# VectorLock-OreVision

See ores/chests through walls | Standalone OK | Best with Core

Part of the **Vector Lock** add-on suite. Minecraft Bedrock, minimum engine 1.21.70.

## Build
On Windows, run:
```powershell
./build.ps1
```
This packages the pack into `VectorLock-OreVision.mcaddon` (build output is git-ignored).

## Notes
- Standalone-capable: works without VectorLock-Core (embedded runtime + peer-election).
- With Core (or Ultimate) installed, this add-on plugs into the shared menu automatically.
