## 🔑 ทุกแอดออนเล่นเดี่ยวได้ — แต่เต็มประสิทธิภาพที่สุดต้องมี Core!

> **ทุกแอดออนทำงานได้ด้วยตัวเองทันที ไม่ต้องมีอะไรเพิ่ม**
> **แต่ถ้าอยากเล่นแอดออนของผมมากกว่า 1 ตัวพร้อมกันแบบเต็มประสิทธิภาพที่สุด
> แนะนำให้ติดตั้ง `VectorLock-Core.mcaddon` ด้วยเสมอ**

### โหมดเดี่ยว (ไม่มี Core)
- แอดออนตรวจหา Core อัตโนมัติตอนเข้าโลก — ไม่เจอ ก็สลับเป็น **โหมดเดี่ยว** เอง
- **ย่อตัว + เข็มทิศ** → เปิดหน้าตั้งค่า**ของแอดออนตัวนั้นโดยตรง** (มีแค่ของมัน ไม่มีเมนูอื่น)
- ค่าที่ตั้งไว้เซฟลงโลกตามปกติ — ลง Core ทีหลัง ค่าเดิมตามไปด้วยทันที

### ทำไมควรมี Core เมื่อเล่น 2 ตัวขึ้นไป
- **จัดการ tick รวม**: ทุกแอดออนวิ่งใน loop เดียวของ Core → ลื่นกว่าแยกกันคนละ loop
- **เมนูรวมหนึ่งเดียว**: ทุกแอดออนโผล่เป็นปุ่มในเมนูเดียว จัดระเบียบ ถอดเข้าออกอัตโนมัติ
- **หน้า Status / ตั้งค่ากลาง (เสียง อนุภาค) / สลับภาษาไทย-อังกฤษ** — มีเฉพาะใน Core
- **Target Mode แชร์กัน**: Bow + Sword ใช้โหมดเป้าหมายชุดเดียวกันผ่าน Core

### วิธีติดตั้ง
1. (แนะนำ) เปิด `VectorLock-Core.mcaddon` ก่อน (ดับเบิลคลิก หรือลากเข้า Minecraft)
2. เปิดแอดออนพลังตัวที่อยากได้ทีละไฟล์
3. เข้าโลก → เปิด Behavior Pack ที่ต้องการ (Ore Vision จะดึง Resource Pack ของมันให้อัตโนมัติ)
4. ในเกม: **ย่อตัว + ใช้เข็มทิศ** เพื่อเปิดเมนู/ตั้งค่า

|---|---|---|

| `VectorLock-AutoShield` | ยกโล่บล็อกดาเมจอัตโนมัติเมื่อโดนโจมตี | เปิด/ปิด |

| `VectorLock-PreEquipShield` | สวมโล่เตรียมพร้อมเมื่อมีศัตรูเข้าใกล้ | ระยะตรวจศัตรู |
| `VectorLock-KillAdrenaline` | Speed + Regen ทันทีที่ฆ่าศัตรูได้ | ระยะเวลา, ระดับบัฟ |

| `VectorLock-MLG` | เสกถังน้ำรับพื้นอัตโนมัติตอนตกจากที่สูง | ระยะสแกนพื้น |
| `VectorLock-Torch` | ปักคบไฟอัตโนมัติในที่มืด | รัศมีเช็คแสง |
